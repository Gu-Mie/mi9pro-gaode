## 已安装旧版时更新

用户已通过 AstroBox 的「快应用」方式安装过旧版，现有 0.1.1 已确认能显示手机导航。继续使用「快应用」安装类型更新即可。

1. 在 AstroBox 选择「快应用」，选择 `Download/NAV-KEEPON-012.rpk` 安装更新。这是版本 0.1.2（版本号 3），与旧版包名及签名一致；可配合当前手机 0.1.3 使用。
2. 退出手环旧页面后重新打开「腕上导航」，检查顶部是否显示「腕上导航 0.1.2」。如 AstroBox 提示同名应用不能覆盖，再仅卸载手环上的旧「腕上导航」后安装此包。
3. 点击「本地演示」，应显示「本地演示 · 非真实导航」、右转箭头和「200 米」；15 秒后退出。这个检查不需要手机互联成功。
4. 重新连接小米运动健康并开始高德导航，让手环停留在导航页面，等待超过原本的自动熄屏时间，检查是否保持亮屏。导航结束、断连、消息过期或离开页面后应恢复正常熄屏。
5. 若仍黑屏，记录是否连「腕上导航 0.1.2」都未出现；若互联或常亮失败，滑动底部「错误详情」并记录错误码。

手环 0.1.2 已通过编译、19 项 JavaScript 测试和 RPK 内容启动检查，并已传到手机、由用户安装确认。最初仅在两端前台时确认可常亮；手机 0.1.3 后续已实现从表盘自动打开并取得用户确认，锁屏持续显示验证另见 [交接文件](../HANDOVER.md)。

## 首次使用 AstroBox 安装

AstroBox 是第三方穿戴管理工具，官方支持列表包含小米手环 9 Pro。以下依据 2026-09-13 查阅的 AstroBox V2 文档整理，具体菜单可能随版本变化。

1. 从 [AstroBox 官方安装页](https://abox.run/docs/usage/install) 下载 Android 版本并安装。首次打开按向导完成蓝牙、附近设备等所需权限设置。
2. 点击 AstroBox 底部胶囊形设备卡片，再点击切换设备，选择导入设备。在手机上自行登录与「小米运动健康」绑定手环时相同的小米账号，完成验证码等验证，导入手环。
3. 按 [官方设备连接指引](https://abox.run/docs/usage/connection)，在手环设置中找到系统操作或我的设备里的「连接新手机」，确认后回到 AstroBox 选择手环 9 Pro，在手机和手环上确认配对。这里选择的是「连接新手机」，不要选择恢复出厂设置。
4. 连接成功后，在 AstroBox 设备页打开应用/快应用卡片，点击右上角加号，选择上面的 RPK 文件。也可以从队列页面点击加号，选择应用资源与文件。如果队列没有自动开始，点击开始按钮。参见 [官方本地资源安装说明](https://abox.run/docs/usage/resource)。
5. 等待安装完成，在手环应用列表中找到「腕上导航」。

## 安装后的互联测试

本工程通过小米运动健康转发数据。安装完成后退出 AstroBox 的设备连接，回到小米运动健康，确认手环重新显示已连接。如未能重新连接，先保留当前错误信息以便排查。

在手机「腕上导航」中开启同步，点击「连接并授权手环」；在手环打开「腕上导航」。发送 15 秒演示导航，检查手环是否显示测试数据、手机是否出现手环确认。成功后再开始高德真实导航测试。

高德地图本身也需要开启发送通知权限及「导航通知」类别。本次首次无法同步时，高德的 POST_NOTIFICATIONS 权限处于关闭状态；开启后才出现可供读取的真实导航通知。

此前手机与手环均使用 0.1.1 时，用户已确认实际显示。手机日志尚未记录手环 ACK，回执通道与长时间后台稳定性仍待单独验证；见 [联调记录](navigation-verification.md)。
