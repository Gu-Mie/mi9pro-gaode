# 首次使用

腕上导航需要 **Android 手机配套应用（APK）+ 小米手环 9 Pro 快应用（RPK）+ 小米运动健康连接**。高德地图继续在手机上负责导航。

## 获取安装包

源码仓库不附带安装包或签名。`outputs/` 是维护者本地目录，克隆源码不会下载其中的文件。请从 [GitHub Releases](https://github.com/Gu-Mie/mi9pro-gaode/releases) 阅读发布说明，取得标明兼容的 APK、RPK 和 SHA-256 校验表。不要把无签名检查产物作为安装包。

当前配套源码为手机 0.2.1 / code 6、手环 0.2.4 / code 9。0.2.4 已构建并传输核验，用户于 2026-09-22 确认安装使用正常；字体加载、滚动、设置保存及亮屏行为尚未获得逐项反馈，长期稳定性仍待验证。此前 0.2.3 的设置页显示反馈不能代替 0.2.4 的具体功能验收。

## 配置顺序

1. 让小米运动健康正常连接手环；手机高德地图需能显示导航通知。
2. 在手机安装维护者提供的已签名 APK。手机 APK 与手环 RPK 的包名都应为 `io.github.mi9pro.navigation`，并使用匹配签名。
3. 在 AstroBox 使用“快应用”类型选择 RPK 安装到手环，具体连接步骤见 [手环安装指南](band-install.md)。不要将 APK 安装到手环，也不要选择重置设备。
4. 安装后恢复小米运动健康连接。打开手机腕上导航，按页面提示授予通知使用权、所需设备权限和互联授权，再开启同步。根据手机系统设置后台运行权限。
5. 在安全、可停留操作的位置，用高德开始导航，检查手环是否打开并显示相同指引。结束导航、关闭同步或离开页面后检查常亮释放。
6. 手环底部齿轮可调整显示。旧设置会保留；更新到 0.2.4 后可点“恢复默认”应用字号 30、箭头 42、粗细 8 的新比例。

如只显示等待状态，依次核对高德是否有导航通知、通知使用权、手机同步开关、运动健康连接与手环应用是否同签名。错误反馈请使用 [贡献指南](../CONTRIBUTING.md)，不要上传真实路线或设备凭据。

## 开发者自行编译

普通贡献者无需签名即可执行 JS 测试、界面预览与 Android 无签名编译。维护现有安装必须恢复原有双端签名，不能由安装包还原私钥。

独立 Fork 如需建立自己的应用身份，必须自行管理包名、双端匹配证书及升级路径；现有项目的构建入口默认保护原应用身份。不同签名不能作为现有发布版的覆盖更新，也不能将不同签名的手机与手环包混用。本次开源准备没有生成、轮换或分发任何签名。
