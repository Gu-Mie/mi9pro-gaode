# 腕上导航 · 小米手环 9 Pro

把 Android 高德地图的导航通知同步到小米手环 9 Pro。首次完成授权后，手机配套程序在后台转发，高德开始导航时请求打开手环导航页。

高德导航通知 → 手机腕上导航 → 小米运动健康互联 → 手环腕上导航。

## 功能

- 显示转向、距离和通知指引；只处理 com.autonavi.minimap，不计算或编造路线。
- 按一次导航控制自动打开，避免每次更新都抢回手环前台。
- 活动导航保留 8 秒心跳，合并突发更新；20 秒没有更新时清除过期指引。
- 导航页面在前台时可保持亮屏，结束、断连或离开页面后释放常亮；手机端可关闭此设置。
- 手机端提供同步开关、连接授权与后台运行设置。
